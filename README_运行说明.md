# 《档案：隐庐》· 档案解密式推理游戏（五案完整版）

一个以**文字阅读 + 关键词搜索**为核心的单机本格推理游戏。你扮演连环专案组警探，
面对五沓互相关联的案件档案（日记、信札、剪报、验尸报告、监控文字记录），通过检索、
比对与时间线还原，逐案指认真凶，并在破案过程中拼出贯穿五部的暗线——「沉璧」。

- **游戏类型**：单机 · 文字推理 · 本格悬疑
- **技术形态**：单文件 HTML（内嵌 JS/CSS），离线运行，无需安装、无需网络
- **目标平台**：Windows PC（双击即玩，任意现代浏览器）

## 如何运行

1. 找到 `《档案·隐庐》五案完整版.html`。
2. **双击**用浏览器（Chrome / Edge 等）打开即可。
3. 离线可玩。
   - **Windows 便携版**（推荐）：存档写入本机 `userData/saves/savegame.json`，关闭后重开仍有进度；启动页提供「继续游戏」/「新游戏」，存档损坏会自动提示且不影响新游戏。
   - **浏览器版**：后退到 localStorage 存档（仅本浏览器本机保留）。
4. 首次启动出现「继续游戏 / 新游戏」选择页；菜单底部可「清除并重置进度」。

> 若双击默认被编辑器打开：右键 → 打开方式 → 选择浏览器。

## 游戏流程（五案顺序解锁）

从左侧「案件菜单」进入。**必须先侦破前一案**才能解锁下一案；已破案可随时回看。

| 顺序 | 案名 | 地点 | 真凶（剧透） |
|---|---|---|---|
| 1 | 《隐庐钟停之时》 | 临江市 · 隐庐公寓 | —— 待你指认 —— |
| 2 | 《镜中倒影》 | 临江市 · 旧租界洋房 | —— 待你指认 —— |
| 3 | 《纸上亡灵》 | 蒲京市 · 大学 | —— 待你指认 —— |
| 4 | 《铜镜迷局》 | 港屿市 · 拍卖行 | —— 待你指认 —— |
| 5 | 《沉璧》（收束篇） | 云泽镇 · 旧宅 | —— 待你指认 —— |

每案内部沿用同一套体验：

1. **案件简报**：先读案发背景。
2. **档案阅读**：6 份档案，点击阅读；搜索框输入人名/日期/地点/物品，命中档案标黄高亮。
3. **时间线还原**：8 个时间槽，为每个槽分别选【日期】＋【事件】；全部匹配 → 进度 100%。
4. **侦查提示**：卡关时点击「揭示下一条」，每案最多 3 条递进提示；已揭示的会随存档保留。
5. **指认真凶**：时间线 100% 后开放，从 4 名嫌疑人中指认。选对 → 结案＋归档该案的「沉璧」暗线线索；选错 → 提示真相要点，可重试。

每破一案，「沉璧 · 暗线档案」会多一条记录。破完第 5 案即通关整个系列。

## 设计说明

- 采用**单文件 HTML**实现（非 Twine/Godot）：Twine(Harlowe) 无法便捷实现
  “跨档案全局搜索＋高亮＋自定义时间线/指认”这套交互；单 HTML＋原生 JS 零依赖、双击离线运行。
- 全部地名与历史人物已虚构化（临江/蒲京/港屿/云泽等），无现实指向。
- 第五部《沉璧》原稿在分享中被截断，已依据暗线设定补齐并自洽收束（见 md 第三、四部分）。

## 方向二 · 三 更新说明（体验深化）

- **当事人独白**：每案 2 段第一人称独白。时间线 100% 解锁「第一段」（指认前），正确指认解锁「第二段」（结案后）；独立「当事人独白」选项卡，并收藏至「沉璧档案」反复查阅。
- **沉璧档案页**：菜单提供「打开沉璧档案」，逐案收录暗线信息与已解锁独白，随案件推进逐步解锁。
- **已破案件标记**：案件选择界面给已破案件加红色「已破」印章并区分底色。
- **游戏内通知**：右上角堆叠提示条（含存档/读档/解锁等关键事件反馈），自动消失。
- **视觉/反馈**：隐藏原生标题栏（Header 可拖动）、页面切换淡入动画、翻页/点击/提示/印章 WebAudio 音效（右上角可静音）、结案红色印章动画。
- **音效开关**：Header「音效：开/关」按钮。
